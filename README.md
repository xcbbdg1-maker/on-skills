# on-skills

> 我对「skill」本身的思考。
> Notes on how to **build, acquire, and adapt** AI / Claude Code skills so they fit your own brain.

这个仓库不放具体的 skill,放的是**对 skill 这件事的思考**——怎么造、怎么借用别人的、怎么把它打磨到和自己的大脑适配、怎么判断一个 skill 有没有真东西。边想边攒,一篇一篇长。

## 为什么单独开这个仓库

具体的 skill(判断逻辑、案例)是**资产**,有的私有;而"**怎么对待 skill**"是**方法论**,可公开、也值得沉淀成独立一层。把"用什么"和"怎么用/怎么造"分开。
