# 004 · skill 怎么集成成一个 agent(方式 + 我的选型)

2026-07-27

## 六种集成方式(由松到紧)

| # | 方式 | 是什么 | 什么时候用 |
|---|---|---|---|
| 1 | **自动共存** | `~/.claude/skills/` 里的 skill 自动可用,Claude 按相关性挑 | 默认;单个 skill 各干各的 |
| 2 | **总指挥 / orchestrator skill** | 一个 skill 编排调用其他 skill(如 us-macro-brief) | 有 2-3 个相关 skill,要串成一条流水线 |
| 3 | **子代理(subagents)** | 用 Agent 工具 spawn 独立上下文并行 / 隔离干活 | 要并行(如同时拆 3 家可比公司)或隔离防串味 |
| 4 | **插件 / MCP** | 打包成 plugin 分发;或接 MCP server 挂外部工具数据 | 要分发给别人,或接外部数据源 |
| 5 | **Agent SDK(写代码)** | 用 Claude Agent SDK 把 skills+工具+逻辑编成**独立程序化 agent** | 要部署成服务 / 后台 / API,不依赖网页或 CLI |
| 6 | **CLI / 定时** | 命令行、cron / 定时任务里跑 | 无人值守、周期性任务 |

> "除了网页"的核心替代 = 本地 CLI + Agent SDK 编程集成 + MCP + 定时。

## 原则:别过度设计,按需升级

**集成度越高 ≠ 越好。** 一个单一 skill 硬套 SDK/子代理是杀鸡用牛刀。选型看**你现在真需要什么**。

## 我(用户)当前的选型

- **pevc-financials-lens 现在**:就用**方式 1(独立 skill)**——它是一把单一分析透镜,还没到需要总指挥的程度。
- **下一步(攒够 2-3 个投研 skill:pevc + 估值 + macro + hk-ipo)**:建一个 **「投研总指挥」orchestrator(方式 2)**,像 us-macro-brief 那样——给一家公司,自动串"财报透镜 → 估值 → 宏观背景 → 窗口"。
- **对比多家公司时**:用 **子代理并行(方式 3)**,每家一个子代理同时拆,再汇总对比。正好配"横向对标同行 + IPO 竞对"的需求。
- **SDK / MCP / 定时**:个人自用暂不需要,先不碰。

## 一句话

**现在保持独立;等投研 skill 攒成一簇,盖个总指挥;要并行对比时,派子代理。** 集成方式跟着"任务复杂度"长,不跟着"技术炫酷度"长。
