# 003 · 两个 skill 看同一家公司:视角互补(audit-craft × pevc-financials-lens)

2026-07-27

一个关于**skill 生态**的观察:我有两个"看公司"的 skill,视角不同、恰好互补。搞清它们的关系,比孤立用任何一个都强。

## 两种视角

- **audit-craft(审计)**:问"**账是不是真的**?"——真不真、公允否、有无重大错报/舞弊。向后看,守门。
- **pevc-financials-lens(投资)**:问"**生意是不是好的、值不值这个价**?"——好不好、贵不贵、退不退得出。向前看,下注。

## 为什么值得放在一起想

1. **交集在"财务规范/退出"**:账干净、收入确认规范、关联交易清晰——既是审计意见的基础,也是 PEVC 判断退出与估值的门槛。**同一件事,两个用途。**
2. **互相当雷达**:
   - 审计→投资:审计的"真伪嗅觉"帮 PEVC 识别粉饰、看穿"账面繁荣"。
   - 投资→审计:PEVC 的"生意嗅觉"帮审计定位风险根源(造假动机、持续经营、该重点查哪个科目)。
3. **一个人跨领域时,视角会迁移**:我审计出身学 PEVC,最大的坎是"别用审计脑子做投资判断"(只盯账真、漏掉生意好坏)。把两种视角显式写下来对照,切换才不串味。

## 落到 skill 上怎么做的

- pevc skill 里放了 `references/视角-pevc-vs-审计.md`(帮审计背景的人切到投资视角)。
- audit-craft 里放了 `references/视角-借pevc看生意.md`(帮审计借投资嗅觉找风险)。
- 这里(on-skills)放的是**上帝视角的那层反思**:两个 skill 不是各干各的,是**一套"看公司"能力的两只眼**。

## 更一般的启发

**当你有两个 skill 在看同一个对象、只是视角不同时,别让它们老死不相往来——显式写清它们的"分工 + 交集 + 互为雷达",这套能力才立体。** 这也是 skill 生态该有的样子:不是一堆孤岛,是能互相引用、互相补位的网。
